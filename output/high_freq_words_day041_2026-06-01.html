📝 今日单词
#401
like /laɪk/
Lv.1 v. 喜欢 prep. 像…一样 adj. 相似的
例句 Example
I like reading books.
我喜欢看书。
#402
limit /ˈlɪmɪt/
Lv.1 n./v. 限制；限度；限制
例句 Example
There is a speed limit on this road.
这条路有限速。
#403
line /laɪn/
Lv.1 n. 线；行；台词
例句 Example
Please stand in a line.
请排队。
#404
list /lɪst/
Lv.1 n./v. 列表；名单；列举
例句 Example
Make a list of things to do.
列一个待办事项清单。
#405
little /ˈlɪtl/
Lv.1 adj./adv. 小的；几乎没有
例句 Example
I have a little sister.
我有一个小妹妹。
#406
live /lɪv/
Lv.1 v. 居住；生活；存活
例句 Example
Where do you live?
你住在哪里？
#407
load /ləʊd/
Lv.1 v./n. 装载；负担；加载
例句 Example
The truck is carrying a heavy load.
卡车载着很重的货物。
#408
local /ˈləʊkl/
Lv.1 adj. 当地的；局部的
例句 Example
This is a local bus.
这是本地公交车。
#409
lock /lɒk/
Lv.1 v./n. 锁上；锁；水闸
例句 Example
Please lock the door when you leave.
离开时请锁门。
#410
long /lɒŋ/
Lv.1 adj./adv. 长的；长久地
例句 Example
It was a long journey.
那是一段漫长的旅程。

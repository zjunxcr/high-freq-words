📝 今日单词
#821
word /wɜːrd/
Lv.1 n. 单词；话；消息
例句 Example
Can you spell this word?
你能拼写这个单词吗？
#822
work /wɜːrk/
Lv.1 v./n. 工作；运转；作品
例句 Example
I have a lot of work to do.
我有很多工作要做。
#823
work out /wɜːrk aʊt/
Lv.1 phrase 解决；锻炼成功；计算
例句 Example
Let's work out this problem.
我们来解决这个问题吧。
#824
worker /ˈwɜːrkər/
Lv.1 n. 工人；工作者
例句 Example
My father is a factory worker.
我父亲是工厂工人。
#825
world /wɜːrld/
Lv.1 n. 世界；地球；领域
例句 Example
The world is very big.
世界很大。
#826
worry /ˈwʌri/
Lv.1 v./n. 担心；烦恼；使忧虑
例句 Example
Don't worry, everything will be fine.
别担心，一切都会好的。
#827
worth /wɜːrθ/
Lv.1 adj. 值得的；值…钱的
例句 Example
This book is worth reading.
这本书值得一读。
#828
would /wʊd/
Lv.1 v. will的过去式；愿意（礼貌）
例句 Example
Would you like some tea?
你想喝点茶吗？
#829
wow /waʊ/
Lv.1 int. 哇；太棒了
例句 Example
Wow, that's amazing!
哇，那太棒了！
#830
wrap /ræp/
Lv.1 v. 包裹；缠绕；结束
例句 Example
Please wrap the gift.
请包装礼物。

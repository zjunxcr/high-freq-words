📝 今日单词
#591
row /rəʊ/
Lv.1 n. 排；列；行
例句 Example
Please stand in a row.
请站成一排。
#592
rule /ruːl/
Lv.1 n./v. 规则；统治；规定
例句 Example
There is a rule against smoking here.
这里有禁止吸烟的规定。
#593
run /rʌn/
Lv.1 v. 跑；运行；管理
例句 Example
I run every morning.
我每天早上跑步。
#594
sad /sæd/
Lv.1 adj. 悲伤的；令人难过
例句 Example
I feel sad today.
我今天感到难过。
#595
safe /seɪf/
Lv.1 adj. 安全的；可靠的
例句 Example
Keep it in a safe place.
把它放在安全的地方。
#596
salt /sɔːlt/
Lv.1 n. 盐；盐类；刺激
例句 Example
This soup needs more salt.
这汤需要加盐。
#597
same /seɪm/
Lv.1 adj. 相同的；同样的
例句 Example
We have the same idea.
我们有同样的想法。
#598
save /seɪv/
Lv.1 v. 救；储蓄；省去
例句 Example
Save your work before you close.
关闭前保存你的工作。
#599
say /seɪ/
Lv.1 v. 说；讲；表示
例句 Example
What did you say?
你说什么？
#600
scene /siːn/
Lv.1 n. 场景；场面；景色
例句 Example
The scene is very beautiful.
景色很美。

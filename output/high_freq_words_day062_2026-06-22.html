📝 今日单词
#611
send /send/
Lv.1 v. 发送；派遣；传达
例句 Example
I will send you an email.
我会给你发电子邮件。
#612
seriously /ˈsɪəriəsli/
Lv.1 adv. 认真地；严重地
例句 Example
Are you serious?
你是认真的吗？
#613
set /set/
Lv.1 v. 设置；放置；建立
例句 Example
Please set the table for dinner.
请摆好餐桌准备吃饭。
#614
set up /set ʌp/
Lv.1 phrase 建立；安装；设置
例句 Example
Let's set up a meeting for tomorrow.
我们安排明天的会议吧。
#615
shake /ʃeɪk/
Lv.1 v./n. 摇晃；握手；奶昔
例句 Example
Shake the bottle well before drinking.
喝之前摇匀瓶子。
#616
shape /ʃeɪp/
Lv.1 n./v. 形状；形状塑造
例句 Example
The cloud is in the shape of a heart.
云形状像一颗心。
#617
share /ʃeər/
Lv.1 v./n. 分享；分担；股份
例句 Example
Let's share this pizza.
我们一起分享这个披萨吧。
#618
she /ʃiː/
Lv.1 pron. 她（主格）
例句 Example
She is my teacher.
她是我的老师。
#619
shoot /ʃuːt/
Lv.1 v. 射击；拍摄；发芽
例句 Example
Don't shoot the bird.
不要射鸟。
#620
shout /ʃaʊt/
Lv.1 v./n. 大喊；喊叫；呼喊
例句 Example
Don't shout, please speak quietly.
请不要喊叫，小声说话。
